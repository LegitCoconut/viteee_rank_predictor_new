# **App Name**: VITEEE College Predictor

## Core Features:

- Rank Input: Allow users to input their VITEEE rank.
- College Prediction: Display a list of potential colleges and programs available based on the user's rank.
- Data Storage: The relevant VITEEE data will be stored.
- Animated Hero Integration: Integrate an animated hero section.

## Style Guidelines:

- Primary color: Deep blue (#1E3A8A) to evoke trust and authority.
- Background color: Light gray (#F9FAFB), near-white to ensure readability and a clean user experience.
- Accent color: Vibrant orange (#EA580C) to highlight important elements and calls to action.
- Headline font: 'Space Grotesk' sans-serif for a modern, tech-forward feel.
- Body font: 'Inter' sans-serif to complement the header and ensure readability.
- Use clear and concise icons from Lucide to represent colleges and programs.
- Maintain a clean, well-organized layout for easy navigation.
- Subtle transitions and animations to improve user experience (e.g., loading indicators, rank input validation).
